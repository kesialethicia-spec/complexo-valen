# Valen Institucional

Crie um site institucional completo, moderno e responsivo para o Complexo Valen, uma marca brasileira localizada em São Luís/MA, conhecida como uma parada completa para caminhoneiros, viajantes, empresas e pessoas em movimento.

O novo posicionamento da marca é:

“SOMOS FEITOS DE MOVIMENTO”

O site deve transmitir movimento, energia, estrada, logística, acolhimento, experiência, modernidade e confiança. O Valen não deve ser apresentado apenas como um posto, mas como um complexo completo que reúne abastecimento, alimentação, descanso, serviços, lojas, hotel, estacionamento, eventos, promoções e experiências.

A estética visual deve seguir uma marca moderna com predominância de laranja vibrante, azul institucional, branco/off-white e pequenos detalhes em amarelo/dourado. Use formas curvas, linhas de movimento, elementos inspirados em estrada/rota/fluxo, cards arredondados, blocos com bastante respiro, interface limpa, elegante e dinâmica. Evite visual escuro demais ou com cara antiga de posto.

O site deve ser robusto, com várias páginas internas, não apenas uma landing page.
